# Make every project visual and example-first

## Direction
Turn the work archive into a simpler, image-led portfolio. Every project should surface real proof before explanatory detail, while keeping the archive easy to scan and the strongest work prominent.

## Changes
- Make the first action on every project card and project page open the strongest available real example; keep “View project details” as the secondary action.
- Add a clear example strip near the top of project pages, before the challenge and ownership sections. Show all verified links with short descriptive labels.
- Import every usable link from the supplied work-examples document, removing tracking parameters while preserving the destination. Include older newsletter issues and every other listed sample.
- For projects without their own link, point first to the most relevant supplied example library or related published work rather than showing a request-for-sample message.
- Use real imagery from supplied assets, public work examples, and Sierra’s uploaded LinkedIn activity export where an image clearly belongs to the work. Do not use unrelated company stock imagery or invent screenshots.
- Simplify project pages into a visual opening, proof/results, a concise “What I did” section, examples, and related work. Reduce repeated labels and long lists.
- Simplify the Work archive controls and card copy so visuals, title, result, and example action carry the page.
- Preserve the evergreen Experience approach: no prominent date ranges, and projects remain grouped by type of work.

## Technical details
- Keep all project content in the existing structured project data so new links and images continue to use the same reusable layout.
- Use direct public links or supplied Drive links only; external examples open in a new tab.
- Extract suitable images from the uploaded LinkedIn PDF only when they are clear, relevant, and legible; store selected images through the project asset flow.
- Keep accessible alt text and mobile-friendly image sizing.
- Add complete per-page social metadata where currently missing while touching the relevant routes.

## Verification
- Confirm every project has a first-click example action on cards and detail pages.
- Compare all URLs in the supplied document against the portfolio data and confirm none are omitted.
- Check Home, Work, and representative project pages on desktop and mobile for visual balance, overflow, and clear hierarchy.
- Confirm every external link opens correctly in a new tab and every real image loads.
