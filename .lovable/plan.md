# Convert projects to inline dropdowns

## Work page

- Keep the existing five work categories and list every project once under its most relevant category.
- Replace project cards with compact project title dropdowns inside each category.
- Show only a short result line and the project’s example links inside each open dropdown.
- List examples vertically, preserving their current order and URLs.
- Show existing small thumbnails only where they already help identify an example; do not add large project imagery.

## Project entry points

- Change homepage project titles to open the matching project on the Work page instead of navigating to a separate project page.
- Change Experience project links the same way.
- Keep existing project URLs available for old/shared links, but remove all normal site navigation into those pages.

## Duplicate prevention

- Keep each project in one category only.
- Detect repeated example URLs across projects and keep each example with the single best-matching project.
- Do not create an “Other Relevant Examples” group.

## Verification

- Test opening and closing project dropdowns on desktop and mobile.
- Confirm homepage and Experience project links land on the correct inline project.
- Check every retained example link is present and no example URL appears twice.
